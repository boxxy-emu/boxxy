Fixes for the game library.

- Swiping the game row now follows your finger. Tap a game to select it, and tap it again to launch.
- Every game can be selected. Before, with a short list, the games at either end couldn't be reached by swiping.
- The controller no longer gets stuck when pressing past either end of the row.
- After swiping, the controller carries on from the selected game instead of jumping back to the start of the list.
- Moving down from the top bar returns to the selected game.

These apply to the single-screen Showcase view and to the lower screen in dual-screen mode.
