The first release of Boxxy, an original Xbox emulator for Android built on xemu.

- Game library with cover art, showcase and grid views, and full controller navigation.
- Vulkan renderer (OpenGL ES fallback), custom Vulkan drivers such as Turnip, background shader compilation.
- Quick Resume, save slots with thumbnails, and per-game settings.
- Dual-screen support: the library and in-game menu use the second screen.
- Online play through Insignia, with guided setup (Settings > Network).
- Backup and restore, and automatic updates from GitHub releases.

You need your own Xbox system files (MCPX boot ROM, BIOS, hard-disk image) and games. Android 13+ on ARM64; tested on the AYN Thor.

Known issue: the 5960 dashboard used for online play can crash after a few minutes idle in its menus.
